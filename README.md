# こつぶホーム

レトロゲームアイドル 村下小粒さんの配信・動画をまとめて見られる **非公式** ファンサイト。

- タイムライン（配信中・これからの配信・過去の配信/動画）
- カレンダー（月ごとの配信回数・時間）
- さがす（タイトル・ゲーム名）
- ランキング（最高同接・再生数・いいね・配信時間）
- ぶんせき（月ごとの配信時間・ゲームごとの配信時間・同接の移り変わり）

データは GitHub Actions が10分ごとに YouTube Data API から取得して `docs/data` に保存します。
対象チャンネルは `config.json` で変更できます（`filter` に書いた言葉がタイトルに入っている動画だけを集めます）。
